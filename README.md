# Barış Tespihat

Standalone Android tesbih counter, ported from the tesbih module in `tekO58/workplanner-app`.

## Included
- 33-bead animated rosary counter
- Multiple counters, goals, rounds and persistent totals
- Counter history and daily statistics
- Bead material and appearance choices
- Vibration and sound preferences
- Floating counter overlay
- Daily plans and reminders

The original `workplanner-app` repository is not modified. This app uses package `com.tekin.tesbih` and its own preferences.

## Build
GitHub Actions builds a debug APK on pushes to this branch and on manual runs. Download the APK from the workflow run's Artifacts section.
